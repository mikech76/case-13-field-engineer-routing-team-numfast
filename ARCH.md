## Ключевые решения и почему

### 1. В браузере, а не на сервере
Публикация — статический хостинг (SourceCraft). Бэкенда там нет. Всё, что нужно
для решения, должно считаться в вкладке. Отсюда: карта квантуется офлайн один раз,
а маршруты и распределение считаются в рантайме.

### 2. Кластерный граф, а не полный CSR
Полный CSR ЦФО в unpacked-виде — 317 МБ только по шести массивам, плюс индекс
сетки на 1.68 млн ячеек. Это не грузится в вкладку.
**Развёрнутый портальный граф — 24 МБ**, и он даёт тот же ответ:
`dist(c_s → c_d) = min по портальным вершинам c_d`.

### 3. Без ограничения `[:8]`
Строители кластеров по умолчанию брали первые 8 входов и 8 выходов на кластер.
Это **форматовое** ограничение, а не нехватка данных: полный CSR покрывает весь
ЦФО. Ограничение рвёт цепочки — кластер без исходящего ребра появляется там,
куда приходит 9-й порт. Восьмикратное расширение на ячейки (705 102 → 817 018)
даёт 98.9 % точно посчитанных времён вместо ~35 %.

### 4. Два CSR с одинаковой топологией
`cg_*` — веса в миллисекундах, `cg_d*` — те же вершины, тот же порядок рёбер,
веса в метрах. Один и тот же SSSP даёт и время, и километры по дорогам.

### 5. Пробки — слот, а не флаг
`k(h)` применяется в `travel.applyTraffic(leg, departMin)`, а не внутри `get()`.
Пока слот выключен, путь расчёта бит-в-бит совпадает с продакшном. Любая
будущая таблица (в том числе порёберная) — объект с полями
`{src, label, note, year, on, kAt(minute)}`.

### 6. Время — единый источник истины
`time_gates(arrive, ws, we, dur, sh0, sh1, lo)` — единственное место, где
решается допустимость. Порядок ворот: **прибытие → окно → смена**.
`we` ограничивает только **старт**, никогда не конец. Нарушений в прогоне 0.

### 7. Молчание = ложь
Раньше на непокрытую ногу возвращалась заглушка `(15 мин, 3.0 км)` — и план
считался на выдуманных числах. Сейчас `travel.get()` возвращает `null`,
заявка уходит в воронку с кодом `UNREACHABLE` из ТЗ, и KPI показывает долю
времён без ответа. **Это стоило 3 «лишних» процента done и это правильно.**

## Структура `site/`

| Файл | Роль |
|---|---|
| `index.html` | каркас, разметка |
| `styles.css` | тёмная консоль, сетка-таймлайн |
| `app.js` | сценарий, карта, сетка, KPI, воронка, детали маршрута |
| `lib/router.worker.js` | загрузка графа, снаппинг, SSSP, полилинии |
| `lib/s0.js` | распределение S0 |
| `lib/traffic.js` | слот пробок `k(h)` |
| `lib/lmap.js` | адаптер карты (Leaflet) |
| `lib/bridge.js`, `lib/numfast_native.wasm` | WASM-мост numfast |
| `vendor/leaflet.*` | вендоренный Leaflet, без CDN |
| `assets/map2/*.bin` | квантованный портальный граф, 24 МБ |
| `data/scenario_100.json`, `scenario_1000.json` | конкурсные срезы |
